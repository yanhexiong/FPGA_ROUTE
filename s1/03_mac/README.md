# S1-03 INT8 乘加单元（MAC）：以 Python 生成参考答案

## 实验目的

神经网络中的卷积、全连接与注意力运算，归结到最底层均为乘加运算 `acc += a * b`。INT8 量化之后，`a`、`b` 为 8 位有符号整数，累加器采用 32 位以避免溢出。S1-04 的脉动阵列即由 4×4 个此类单元构成。

本实验同时引入后续实验将一直沿用的验证方法：**以 Python 计算参考答案，在硬件仿真中逐周期比对**。

## 文件说明

| 文件 | 编写者 | 作用 |
|---|---|---|
| `mac.v` | **实验者** | 乘加单元，接口已经给定 |
| `gen_vectors.py` | 已给出 | 随机生成 2000 个周期的输入，以 Python 计算每个周期之后 `acc` 的正确值，写入 `vectors.hex` |
| `tb_mac.v` | 已给出 | 读取 `vectors.hex`，逐周期向 `mac` 施加输入并比对输出 |

## 规格

每个时钟上升沿，`acc` 按以下优先级（自上而下递减）更新：

| 条件 | 操作 | 用途 |
|---|---|---|
| `rst` | `acc <= 0` | 复位 |
| `in_valid && clear` | `acc <= a*b` | 开始新一轮点积，写入第一项 |
| `in_valid` | `acc <= acc + a*b` | 累加 |
| `clear` | `acc <= 0` | 仅清零 |
| 其他 | 保持不变 | 上游无有效数据 |

`a`、`b` 为 8 位补码，取值范围为 −128 至 127。`acc` 为 32 位补码，溢出时按硬件方式回绕；本实验的测试不会触发溢出。

## 实验步骤

1. 阅读 `gen_vectors.py`，理解参考模型的计算方式，以及每行十六进制数据中各字段的含义。可修改 `SEED` 生成多组测试数据。
2. 实现 `mac.v`，重点关注**符号处理**：
   - 在 Verilog 中，表达式只要有一个操作数为无符号数，整个表达式即按无符号数计算，负数将被视为很大的正数。
   - 端口已声明为 `signed`，中间变量同样须声明为 `signed`，例如 `wire signed [15:0] p = a * b;`。
   - 8 位乘 8 位的乘积用 16 位表示即可。请思考其原因。
3. 运行 `make`，它将先运行 Python 脚本，再运行仿真。通过时输出 `PASS：2000 拍全部和 Python 参考答案一致`。
4. 未通过时，查看第一条 FAIL 对应的 `a`、`b` 与 `acc`：
   - 若结果为很大的正数，通常是符号扩展有误。
   - 若仅在 `clear = 1` 的周期出错，通常是优先级有误。
5. 通过后进行对照实验：删除乘积 `p` 的 `signed` 声明，再次运行，观察符号错误的具体表现，然后恢复原代码。

## 完成标准

- `make` 输出 PASS。
- 能够解释：8 位乘 8 位的乘积为何需要 16 位；累加器为何采用 32 位。并以 ResNet 单层至多累加数千项为例，估算 32 位是否足够。
- 理解 `vectors.hex` 中每一位的含义，能够修改 Python 脚本以增加新的测试模式，例如连续 1000 个周期均输入 −128 × −128。
